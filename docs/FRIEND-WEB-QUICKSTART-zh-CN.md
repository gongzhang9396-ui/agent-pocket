# iPhone + Windows 朋友试用说明

你在 iPhone 网页控制自己的 Windows 电脑。Relay 由朋友提供，电脑上的 Agent 和模型账号仍由你自己准备；不需要安装 Android App。

## 管理员先做一次

在同一 Relay 的 `/admin/` 新建普通用户，勾选“网页首次开通（iPhone / 浏览器，需绑定验证码）”。单独发送用户名、至少 12 位的初始密码、`/app/` 地址和 Windows Host 安装包。不要共享管理员账号，也不要把现有账号改名给朋友。

新账号在首次网页开通前显示“待激活”。如果之前建立的是 Android 开通账号，先取消这个**尚未激活且没有设备/电脑**的账号，再重新建立网页开通账号；已激活的旧账号仍走原来的密钥迁移流程，不能重新生成账户密钥。

## 1. iPhone 首次开通

1. 在 Safari 打开管理员给的 `/app/` 地址，输入独立账号和密码。
2. 点击“开通并继续”。网页在本地生成加密密钥，不需要先借一台 Android。
3. 在支持 TOTP 的验证器中添加账号：同一台 iPhone 可点“在这台手机的验证器中打开”，或手动复制密钥；在其他设备上可扫描二维码。参数为 SHA-1、6 位、30 秒。
4. 输入验证器当前的验证码完成绑定，保存只显示一次的 10 个恢复码，再点击“完成设备验证”。
5. 自己的 iPhone 可以保留“信任此浏览器”；借用手机时取消勾选。重新打开网页仍需密码解锁；在线会话失效后还需验证码。

初次进入没有电脑、没有任务是正常的，接下来绑定自己的电脑。可以先完成开通，再扫描 Host 二维码，避免五分钟配对码过期。

## 2. 安装 Windows Host

准备 Windows 10/11 x64、已安装并登录的 Codex 桌面端，以及至少一个实际存在的项目目录。Host 包含 Node.js 运行时、Bridge 和 Desktop Attach 插件，不包含任何人的模型账号、密码或 Host 身份。

1. 解压试用包，用 PowerShell 的 `Get-FileHash -Algorithm SHA256` 核对 EXE 与 `SHA256SUMS.txt`。本包附有项目 Ed25519 签名；目前没有 Windows Authenticode 证书，可能出现 SmartScreen。只安装来自管理员且校验一致的文件。
2. 用自己日常登录 Codex 的 Windows 用户运行 `AgentPocketHost-0.3.2-windows-x64.exe`。
3. Relay 地址已预填，一般不修改。项目白名单只填你允许操作的目录，例如 `D:\Projects;E:\Work`；不要选择整个系统盘。附件目录选择空间充足的本地位置。
4. 需要查看和续写 Codex 桌面任务时，保留“同时连接 Codex Desktop”。安装完成后打开配对助手；也可从开始菜单打开“Agent Pocket 配对助手”。

## 3. 绑定自己的电脑

1. 配对助手默认显示 **iPhone 网页二维码**。用 iPhone 相机扫码，在 Safari 打开链接；也可以复制网页链接后打开，或粘贴到网页的“绑定电脑”。
2. 登录、解锁或首次开通后，网页弹出“连接自己的电脑”。点击“查看电脑”，核对电脑名称、服务端和公钥指纹，确认确实来自自己的配对助手，再点“确认绑定这台电脑”。
3. 保持助手打开，等待电脑显示“绑定成功”。网页会更新电脑列表，点击“查询连接状态”或选择自己的电脑。
4. 配对码五分钟有效，过期点“刷新二维码”。绑定返回不确定时先查询状态，不要反复重新绑定。配对码可以授权绑定电脑，不要转发二维码原图或链接给其他人。

原 Android App 使用助手中的“Android App 码”按钮切换二维码，旧配对协议仍可用。

## 4. 最小体验测试

先确认电脑在线，再打开一条已有的桌面任务，读取最新消息。要完整控制一个新任务，可从网页新建 Bridge 任务，发送一个不会修改文件的简单指令；随后尝试续写和一份小附件。

Desktop 的操作按钮根据真实 Agent、任务归属及当前能力显示。支持转发的原生命令/文件审批可在网页处理；身份验证或不支持的审批仍需回桌面处理。网页不能通过切换目标获得本来没有的写权限。

附件每次合计最多 3 个，单图 450 KiB、单文件 512 KiB、总量 800 KiB。电脑休眠或退出 Windows 登录后会离线；关闭 iPhone 网页不会中断已经在电脑运行的任务。

## 遇到问题

- **电脑在线但没有任务：** 确认桌面端已经打开过项目，任务目录在 Host 白名单中，Host 和桌面端使用同一个 Windows 用户。若出现 Agent Pocket Hook 信任提示，请检查来源后处理，再刷新任务。
- **配对码过期：** 先完成网页开通和验证码绑定，再刷新电脑二维码、重新扫码。
- **忘记验证码：** 使用保存的一次性恢复码；没有恢复码时联系管理员重置验证码绑定。
- **忘记密码：** 联系管理员重置。已经激活的账号重置密码不会删除电脑和历史，但网页密钥包需要可信设备或离线恢复材料重新迁移。
- **锁定 / 退出 / 忘记：** 锁定清除当前页面的密钥与内容；退出撤销本次网页会话；忘记会清除本地记录并尝试撤销设备。网络失败时页面会明确提示服务器撤销尚未完成。

需要排查时只提供时间、状态、截图和复现步骤；不要发密码、恢复码、Token、完整配对二维码或任务秘密。共享 Relay 时须信任运营者和它提供的网页代码；密码直登不能抵御恶意 Relay。
