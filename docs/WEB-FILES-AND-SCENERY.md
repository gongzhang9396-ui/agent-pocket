# 网页风景皮肤与文件（2026-11-05）

网页仍使用现有 React/Relay/Host 与加密通道。iOS 外壳载入服务器 `/app/`，网页发布后重新打开即可使用新界面；原生导航栏、签名有效期及系统能力不会随网页更新改变。Android 原生重写和灵动岛不在本次范围。

## 界面

账号与设置中的“窗外的风景”提供纸间、像素、画室，持久化 ID 仍为 plain/pixel/oil。白色阅读区配底部水乡、车站、湖畔风景；控件形状、标题字形、状态点与输入区跟随皮肤。图片是装饰，功能和文字不烘焙在图片里。

## 上传

新建任务与继续对话共用附件组件，可选择、预览和移除附件。编码完成前禁止提交；已知失败保留草稿，结果未知沿用原有回执恢复流程。

沿用现有端到端消息预算：最多 3 个附件，单张图片 450 KiB、单个文件 512 KiB、合计 800 KiB。支持 PNG/JPEG/WebP 及文本、PDF 等原有 Host 类型。大文件暂不支持上传，不会静默截断。

## Codex 返回文件

Host 新增 artifacts-v1、artifact/list、artifact/read。仅解析当前任务助手回复中的明确 Markdown 本地文件链接，忽略用户消息、工具输出与远程 URL。允许当前任务目录及该会话专属 generated_images 目录；路径仍须通过项目范围校验。隐藏路径、链接/联接点、硬链接、越界路径与变化中的文件被拒绝。

文件卡片绑定设备、会话和消息。读取授权保留 15 分钟，单文件上限 32 MiB，以 192 KiB 分块通过既有加密 RPC 读取。Relay 不接收明文文件路径或建立公开文件下载地址。

PNG/JPEG/WebP/GIF 支持内嵌和放大预览；512 KiB 以内的文本支持页内预览。PDF、Office、ZIP 等显示文件卡片与保存入口；不会在网页执行 HTML/SVG。图片超过 4 MiB 时由用户点选后读取。刷新对话可重新取得过期授权。

桌面浏览器使用文件下载，移动端优先使用 Web Share。iOS 外壳无法分享某些文件时提示 Safari；未实现原生下载代理。旧 Host 的明确“未知方法 artifact/list”会显示更新提示，不影响原有聊天。文件已移动、超限或不在可分享范围时显示原因。

## 验证与限制

Host 全量测试 170/170；Relay 串行全量 69/69，默认并行曾出现既有激活测试 ECONNRESET，单项重试及串行复验通过。Web 构建和类型检查通过，最终安装版本的文件边界测试 2/2。

真实生产组件的合成数据验收：新建任务携带文件、文本预览、2.3 MB 图片分块与放大、皮肤切换；320/390/1280 宽度未发现横向溢出。尚未进行真实 iPhone 的系统分享/保存验收，浏览器自动下载事件检测也未得到成功回执，不能将此当作完整下载链路通过。
